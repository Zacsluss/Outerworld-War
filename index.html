MULTIPLAYER

Lockstep over your LAN, or the internet through a tunnel. One room code, and everyone types it.
On a LAN: everyone opens this page from the same server address (see the LAN URL printed by serve.js), connects, and the host presses START. Leave Room empty.
Over the internet: the host runs PLAY-ONLINE.bat, then shares the https link it prints AND a room code. Everyone types the same code. The code is what keeps strangers out of your game.
In the desktop app: the host presses HOST A GAME and reads out the address it shows; everyone else types that into Server and presses CONNECT. Over the internet the host still needs a tunnel or a port forward to that port.

SETTINGS

Audio starts muted every time the page loads. Unmuting lasts for this session only.
In game: A attack-move, M move, S stop, H hold, P patrol, B build, V advanced build. Ctrl+1-9 control groups, Tab cycles the selected kind, comma finds an idle worker, Ctrl+A selects the army, Backspace centres on the selection.
Ctrl+M mutes, F1 is help, F3 the codex, F10 the pause menu (its Settings changes the same options), +/- the speed.
